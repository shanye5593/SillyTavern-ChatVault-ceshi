# SillyTavern ChatVault · 测试版（ceshi）

> ⚠️ **这是 ChatVault 的测试仓库**，正式版在 [SillyTavern-ChatVault](https://github.com/shanye5593/SillyTavern-ChatVault)。
> 这里的版本可能不稳定、可能有 bug，建议在不重要的酒馆实例里验证。
> 测试通过的功能才会推送到正式仓库。

---

## 安装（测试版）

酒馆 → 扩展 → 下载扩展和资源 → 粘贴：
```
https://github.com/shanye5593/SillyTavern-ChatVault-ceshi
```

如果你已经装了正式版，建议先卸载正式版再装测试版，避免冲突。

---

## 当前测试中的功能（v0.3.0-test）

- 当前正在使用的聊天卡片高亮
- 提取规则（与现有排除规则并存）
- 卡片折叠区
- 阅读模式（面板内分页阅读全部楼层）
